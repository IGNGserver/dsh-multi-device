# DSH 多设备插件展示官网设计说明 (`dsh-multi.igng.net`)

## 定位与视觉原则

官网面向日常使用 DeepSeek Harness (DSH) 管理多台开发机的开发者，采用与 DSH Desktop / Web 原生一致的界面语言：

- **双色原生理性主题**：默认跟随系统 (`prefers-color-scheme`)，并在顶部导航保留「跟随系统 / 浅色 / 深色」三态切换器（状态写入 `localStorage['dsh-md-site-theme']`）。
  - 浅色主底 `#ffffff`，侧栏与分区次底 `#f9fafb`，主文本 `#0f1115`，主按钮实心黑底白字。
  - 深色主底 `#151517`，侧栏与分组次底 `#1b1b1c`，卡片层级 `#232324 / #2c2c2e / #353638`，主文本 `#f9fafb`，主按钮实心白底黑字。
- **零外部 CDN 字体与零炫技动效**：系统字体栈原生排版，移除深空粒子背景、3D 滚动劫持与发光边框；保留「装上插件（默认 1:1 交互窗口）」与「安装前（2×2 平面对比）」的克制切换。
- **信息分层**：
  1. 首屏聚焦直觉问题解决与真实可点可写的 DSH 交互工作台；
  2. 「顺手在哪」说明保活不丢草稿、状态胶囊提醒与 Git 仓库识别；
  3. 「安心边界」用日常语言明确四条承诺：远程零安装、文件不跨机同步、本地侧边栏不混杂、复用已有 `~/.ssh/config`；
  4. 「三步安装」主打 DSH 设置里粘贴 `.tgz` URL 安装，终端 CLI 命令与 4 条排查清单默认折叠；
  5. `#architecture` 位于底部，默认折叠收纳 SSH 环回转发、Keep-Alive 机制与支持环境边界等技术细节。

## 事实与约束边界

- 插件仅安装于本地 DSH Desktop（`--profile desktop`）或本机 `127.0.0.1` / `localhost` 的 HTTP DSH Web（`--profile web`）。
- 未发布到公共 npm，安装地址固定指向 GitHub Release 发布的 `.tgz` 归档包。
- 不支持远程浏览器直访父页面、HTTPS 嵌套 HTTP 或 IPv6 父页面。
